Stage 1

Your first repository.

A browser and a free GitHub account. Work in Codespaces. Nothing to install, and no folder on your computer.

Start stage 1 Stage guide

Read first

These chapters explain the ideas. Skip installing Git. Create git-lab from the template, not with git init.

  • Your first repository
  • The three areas of Git
  • Making commits
  • Viewing history
  • Ignoring files

Do the work

  1. Choose Start stage 1. If Stage says None, choose 1. Then Create. GitHub shows the issue page. That is expected. Do not open Git CMD.
  2. Wait about a minute and refresh. The bot comment has three steps: create git-lab, open it in Codespaces, and a command block. Paste every line of that block. Do not skip to index.html.
  3. Yellow bars for greeting-a and greeting-b are for stage 3. Ignore them.
  4. The last step is Submit stage 1. If a check is empty, fix it in the same codespace and submit again. Do not Start again.

Copying another learner's repository fails, because the code belongs to the account that started the stage.

If a screen looks wrong

Do the work

  1. Choose Start stage 1, then Create. GitHub shows the issue page. That is expected.
  2. Wait about a minute and refresh. The portal replies with your personal code and three steps: a link that creates your git-lab, a link that opens it in Codespaces with a terminal in the browser, and the commands to paste there.
  3. Follow the three steps in the reply. The last one is a link that submits your work. A second reply lists every check.

If a check fails, fix it in the same codespace and use the submit link again, up to five times a day. Copying another learner's repository fails, because the code belongs to the account that started the stage.

Your first repository.

Create a public lab from the template, then prove three commits, a changed README, a .gitignore line, and your personal code.

Do the work

  1. Open a Start issue and choose stage 1. The reply contains a personal code. Keep that start time: only commits after it count.
  2. On rm-git-lab-template, choose Use this template, include all branches, and name the copy git-lab. The repository must be public.
  3. Commit the code as the only line of .stage/stage-1.txt on main.
  4. Change README.md and commit it.
  5. Add a .gitignore line that is exactly *.log and commit it.
  6. Make at least three commits in total after the Start issue. Use the email that GitHub has verified for your account, or the commits will not count.
  7. Open a Submit issue. Set the repository to your-username/git-lab.

The reply lists every check that failed. You can submit again, up to five times a day. Copying another learner's repository fails, because the code belongs to the account that started the stage.

Viewing history

Git remembers everything, and a handful of commands let you read that memory in many different ways.

Course

The last line of the stage 1 block is git log --oneline. You should see at least three commits you just made. If you see only one or two, you skipped part of the block. Fix: only two commits

9.1 git log: the history list

$ git log
commit 9a1c4e7d2b8f0c3a5e6d7f8a9b0c1d2e3f4a5b6c (HEAD -> main)
Author: Your Name <you@example.com>
Date:   Mon Oct 5 10:12:03 2026 +0530

    Fix typo in README

commit 3f2a9c1e5b7d4a8c9d21f6e5a4b3c2d1e0f9a8b7
Author: Your Name <you@example.com>
Date:   Mon Oct 5 09:40:11 2026 +0530

    Add README

Newest commits come first. Press q to leave the scrolling view.

9.2 Making log readable

CommandResult
git log --onelineOne line per commit
git log --graph --oneline --allDraw branches as an ASCII graph
git log -3Only the last three commits
git log --author="Priya"Commits by one author
git log --since="2 weeks ago"Commits from a time range
git log --statShow which files changed in each commit
git log -- path/file.txtHistory of one file
git log --grep="login"Search commit messages
 
$ git log --oneline
9a1c4e7 Fix typo in README
3f2a9c1 Add README
Tip

The git lg alias from Chapter 5 gives you this compact graph view in three letters.

9.3 git show: look inside one commit

$ git show 3f2a9c1
commit 3f2a9c1e5b7d4a8c9d21f6e5a4b3c2d1e0f9a8b7
Author: Your Name <you@example.com>

    Add README

diff --git a/README.md b/README.md
new file mode 100644
+# Hello Git

You only need the first 7 or so characters of the hash, as long as they are unique.

9.4 git diff: compare changes

Diff shows what changed. Which two things it compares depends on the options.

diff --git a/README.md b/README.md
@@ -1 +1,2 @@
 # Hello Git
+More text

Lines beginning with + were added, lines beginning with - were removed, and @@ marks the position in the file.

CommandCompares
git diffWorking directory against staging area
git diff --stagedStaging area against the last commit
git diff HEADWorking directory against the last commit
git diff 3f2a9c1 9a1c4e7Two specific commits
git diff main featureTwo branches

9.5 git blame: who changed this line

$ git blame README.md
3f2a9c1e (Your Name 2026-10-05 1) # Hello Git
9a1c4e7d (Priya Shah 2026-10-05 2) More text

Blame shows, for every line, the commit and author that last changed it. Use it to ask "why is this here?", not to assign fault.

9.6 Other handy commands

  • git shortlog -sn counts commits per author.
  • git show HEAD~2 shows the commit two steps before the latest.
  • git log -p shows the full patch for each commit.

9.7 Common mistakes

  • Being stuck in the pager. Press q to exit a long log.
  • Expecting git diff to show staged changes. Add --staged for those.
  • Pasting a full 40-character hash. The short form works.
Quick recap
  • git log lists history; --oneline and --graph make it readable.
  • git show displays one commit in full.
  • git diff compares areas, commits or branches.
  • git blame shows who last changed each line.

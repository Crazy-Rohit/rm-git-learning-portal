Your first repository

Creating a repository turns an ordinary folder into a project that Git can track.

Course

For the Git Learning Portal, do not run git init or mkdir on your computer. Create git-lab from the template in the browser, then open it in Codespaces. This chapter still uses git init so you can see what a repository is. Stage 1 guide · I already have GitHub. Do I still make a folder?

6.1 Creating a repository with git init

A repository is a folder that Git is watching. Any folder can become one with a single command.

$ mkdir hello-git
$ cd hello-git
$ git init
Initialized empty Git repository in /home/you/hello-git/.git/

That is all. Git created a hidden folder called .git inside your project. Everything Git knows about your project lives in that folder: the history, the settings and the branches. Your own files stay where they are.

Warning

Never delete the .git folder by accident. If you delete it, the project becomes an ordinary folder again and its entire history is gone.

6.2 What is inside the .git folder

You do not need to edit these files, but it helps to know what they are.

ItemWhat it holds
HEADA pointer to the branch or commit you are currently on
configSettings for this repository only (the local level from Chapter 5)
objects/Every file version and commit Git has saved, stored by hash
refs/Pointers to branch tips and tags
indexThe staging area (explained in the next chapter)
 
$ ls -a
.  ..  .git
$ ls .git
HEAD  config  description  hooks  info  objects  refs

6.3 Checking the state with git status

git status is the command you will type most often. It tells you which branch you are on and what has changed.

$ git status
On branch main

No commits yet

nothing to commit (create/copy files and use "git add" to track)

Now create a file and ask again.

$ echo "# Hello Git" > README.md
$ git status
On branch main

No commits yet

Untracked files:
  (use "git add <file>..." to include in what will be committed)
	README.md

nothing added to commit but untracked files present (use "git add" to track)

Untracked means Git can see the file but is not recording it yet. You will fix that in the next chapter.

6.4 Cloning an existing repository

Often you start from a project that already exists online. git clone downloads the whole repository, history included.

$ git clone https://github.com/git/git-scm.com.git
Cloning into 'git-scm.com'...
$ cd git-scm.com

Clone creates a new folder named after the repository. Cloning from GitHub is covered fully in Part 4.

6.5 Common mistakes

  • Running git init inside another repository. You then have a repository inside a repository, which confuses Git. Check with git status first; if it says "not a git repository" you are safe to initialise.
  • Initialising your home folder. Always create a project folder first. Running git init in ~ makes Git try to track everything you own.
  • Running Git commands outside a repository. The error fatal: not a git repository simply means you are in the wrong folder.
  • Making a folder on your computer for the course. A folder is not a GitHub repository. For stage 1, use the template link in the Start comment, then Codespaces.
  • Opening the yellow Compare & pull request banners on git-lab. greeting-a and greeting-b are for stage 3. Ignore them in stage 1. Yellow banners
Tip

Your terminal prompt can show the current branch. Git Bash does this by default, and tools such as Oh My Zsh add it on macOS and Linux.

Quick recap
  • git init turns a folder into a repository by creating a hidden .git folder.
  • .git holds all history and settings; never delete it.
  • git status shows your branch and which files are untracked, modified or staged.
  • git clone copies an existing repository with its full history.

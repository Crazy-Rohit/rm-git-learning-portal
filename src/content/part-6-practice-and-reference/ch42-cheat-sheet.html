Cheat sheet

One place to look up the commands you use most, grouped by what you want to do.

42.1 Setup and configuration

CommandPurpose
git config --global user.name "Name"Set your name
git config --global user.email "mail"Set your email
git config --global init.defaultBranch mainDefault branch name
git config --listShow settings

42.2 Starting a repository

CommandPurpose
git initCreate a repository here
git clone <url>Copy a remote repository
git remote add origin <url>Connect a remote

42.3 Snapshots

CommandPurpose
git statusShow what changed
git add <file> / git add .Stage changes
git add -pStage part of a file
git commit -m "msg"Commit what is staged
git commit --amendFix the last commit
git rm <file> / git mv a bDelete or rename a file

42.4 Inspecting

CommandPurpose
git log --oneline --graph --allCompact history graph
git show <commit>One commit in detail
git diff / git diff --stagedUnstaged / staged changes
git blame <file>Who changed each line
git reflogWhere HEAD has been

42.5 Branching and merging

CommandPurpose
git branchList branches
git switch -c <name>Create and switch
git switch <name>Switch
git merge <branch>Merge into the current branch
git rebase <branch>Replay commits on another branch
git cherry-pick <hash>Copy one commit
git branch -d <name>Delete a merged branch

42.6 Remotes

CommandPurpose
git fetchDownload without merging
git pull / git pull --rebaseFetch and merge or rebase
git push / git push -u origin <branch>Upload commits
git push --force-with-leaseSafer force push
git remote -vList remotes

42.7 Undoing

CommandPurpose
git restore <file>Discard working changes
git restore --staged <file>Unstage
git reset --soft HEAD~1Undo commit, keep changes staged
git reset --hard HEAD~1Undo commit and discard changes
git revert <commit>Undo with a new commit
git clean -nPreview removal of untracked files

42.8 Shelving and marking

CommandPurpose
git stash / git stash popShelve and restore work
git stash -uInclude untracked files
git tag -a v1.0.0 -m "msg"Annotated tag
git push origin --tagsPush tags

42.9 Advanced

CommandPurpose
git rebase -i HEAD~nEdit the last n commits
git bisect startFind a bug by binary search
git submodule update --init --recursiveFetch submodules
git lfs track "*.psd"Store large files with LFS

42.10 Symbols worth knowing

SymbolMeaning
HEADThe commit you are on
HEAD~1One commit before HEAD
origin/mainYour copy of the remote main branch
main..featureCommits in feature that are not in main
.The current folder
Quick recap
  • Bookmark this chapter for quick lookups.
  • Learn the groups: setup, snapshots, branches, remotes, undo.
  • When unsure, git status and git log --oneline --graph --all tell you where you are.
Practice exercise
  • Print this chapter or keep it open while you work for one week.
  • Pick five commands you do not yet use and try each once.

Remotes and cloning

A remote is a copy of your repository stored somewhere else, usually on GitHub, and cloning is how you get one onto your machine.

21.1 What a remote is

So far everything lived on your computer. A remote is another copy of the repository on a server. Teammates push their work to it and pull each other's work from it. By tradition the main remote is called origin.

21.2 Creating a repository on GitHub

  1. Sign in at github.com and choose New repository.
  2. Enter a name such as hello-git and an optional description.
  3. Choose Public (anyone can see it) or Private (only people you invite).
  4. If you already have a local project, leave the options to add a README, .gitignore and licence unchecked, so the two do not clash.
  5. Select Create repository. GitHub then shows the commands you need.
Caution

Check the visibility before you create the repository. Anything pushed to a public repository can be seen and copied by anyone.

21.3 Connecting an existing local project

$ git remote add origin https://github.com/your-username/hello-git.git
$ git branch -M main
$ git push -u origin main

The first line registers the remote, the second makes sure your branch is called main, and the third uploads your history. The -u flag remembers the link, so later you can type only git push.

21.4 Cloning an existing repository

$ git clone https://github.com/your-username/hello-git.git
Cloning into 'hello-git'...
$ cd hello-git

Cloning downloads the full history, sets origin automatically and checks out the default branch. To use another folder name add it at the end: git clone <url> my-folder.

21.6 HTTPS or SSH

Every repository has two kinds of address.

HTTPShttps://github.com/user/repo.gitToken or credential manager

Chapter 23 explains how to set up each one.

21.7 Common mistakes

  • Cloning inside another repository. Clone into a clean folder.
  • Adding a README on GitHub and also locally. The histories differ, and your first push is rejected. Create the repository empty instead.
  • Pushing to the wrong remote. Check git remote -v first.
Quick recap
  • A remote is another copy of the repository; the main one is called origin.
  • Create a repository on GitHub, then git remote add origin <url> and git push -u origin main.
  • git clone <url> copies a repository with its history.
  • Addresses come in HTTPS and SSH forms.

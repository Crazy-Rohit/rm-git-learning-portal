Installing Git

Installing Git takes about five minutes on any operating system, and you can confirm it worked by running git --version.

4.1 Pick your operating system

Tip

The tabs below try to open on your own operating system. Choose another tab if you set up a different machine.

  1. Download the installer from the official website, git-scm.com.
  2. Run it. The defaults are fine for beginners, but check these screens:
    • Default editor: choose Visual Studio Code if you have it.
    • Initial branch name: choose "Override the default branch name" and enter main.
    • PATH environment: keep "Git from the command line and also from 3rd-party software".
  3. Finish, then open Git Bash from the Start menu.

Or use one command in PowerShell:

$ winget install --id Git.Git -e --source winget

Let macOS install the command line tools. If Git is missing, a window offers to install it.

$ git --version

With Homebrew you can install a newer version:

$ brew install git

Use your distribution's package manager.

# Debian, Ubuntu
$ sudo apt update
$ sudo apt install git

# Fedora
$ sudo dnf install git

# Arch
$ sudo pacman -S git

4.2 Verify the installation

Open a new terminal window and run:

$ git --version
git version 2.45.0

Your version number will probably differ, and that is fine. Any reasonably recent version works with this handbook.

4.3 Common mistakes

  • Terminal opened before installing. It does not see new programs until you close it and open a new one.
  • "git is not recognized" on Windows. The PATH option was skipped. Run the installer again and choose the recommended PATH option.
Important

Download Git only from git-scm.com or your system's package manager, never from an unofficial site.

Quick recap
  • Windows: installer from git-scm.com, or winget.
  • macOS: git --version triggers installation, or use Homebrew.
  • Linux: install the git package.
  • Always confirm with git --version.
Practice exercise
  • Install Git, open a fresh terminal and run git --version.
  • Run git help and read the list of common commands. You meet most of them in Part 2.

First-time configuration

Before your first commit you must tell Git who you are, because every commit records its author's name and email.

5.1 The three configuration levels

Git reads settings from three places. A more specific level overrides a more general one.

LevelFlagApplies toTypical use
System--systemEvery user on the computerRarely changed
Global--globalAll repositories of your user accountYour name, email and editor
Local--local (default)One repository onlyA different email for one project

5.3 Check your settings

$ git config --list
user.name=Your Name
user.email=you@example.com
init.defaultbranch=main
core.editor=code --wait

# read a single value
$ git config user.name
Your Name

Settings live in a plain text file called .gitconfig in your home folder. You can open it in an editor and change values by hand.

5.4 Time-saving aliases

An alias is a short name for a longer command. Add these later, once you are comfortable.

$ git config --global alias.st status
$ git config --global alias.co checkout
$ git config --global alias.br branch
$ git config --global alias.lg "log --oneline --graph --all"

After this, git st does the same as git status.

5.5 Common mistakes

  • Skipping the identity step. Git may refuse to commit, or guess a wrong name and email from your computer.
  • Forgetting quotes around a name with a space, such as "Your Name".
Warning

Commit emails are public in a public repository. If you do not want your real address exposed, use the private no-reply address from your GitHub email settings.

Quick recap
  • user.name and user.email are mandatory; set them once with --global.
  • Set init.defaultBranch main so new repositories start on main.
  • Configure an editor and line endings for your operating system.
  • git config --list shows everything Git currently knows about you.
Practice exercise
  • Set your name and email, matching your GitHub account.
  • Set the default branch to main and choose your editor.
  • Run git config --list and check every value.
  • Create the git lg alias. You will use it in Part 2 to view history.

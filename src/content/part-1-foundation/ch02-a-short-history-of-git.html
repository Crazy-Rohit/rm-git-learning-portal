A short history of Git

Git was created in April 2005 by Linus Torvalds, the creator of Linux, because the Linux kernel project suddenly lost the version control tool it depended on.

2.1 Before Git: the BitKeeper story

The Linux kernel is one of the largest collaborative software projects in the world. Until 2002 its changes were passed around as patches and archives, which did not scale. From 2002 the kernel team used a proprietary distributed tool called BitKeeper, offered to the project free of charge.

In April 2005 the relationship broke down. The company behind BitKeeper withdrew the free licence after a dispute about reverse-engineering its protocol. The kernel developers now had thousands of contributors and no tool.

2.2 A tool built in days

Torvalds found no existing tool that met his goals, so he wrote a new one. His requirements:

  • Speed: applying a patch should take seconds, even for a huge project.
  • Simple design: a small, understandable core.
  • Parallel work: thousands of branches that merge easily.
  • Fully distributed: no single central server required.
  • Integrity: impossible to change history without anyone noticing.

A first version worked within days, and the kernel began using Git for its own development within about two weeks. The name "git" is British slang for an unpleasant person; Torvalds has joked that he names his projects after himself. Junio Hamano has maintained Git since July 2005, and Git 1.0 was released in December 2005.

2.4 Why Git won

  • It is fast, because most operations happen on your own machine.
  • Branching is cheap, so teams create branches freely.
  • It stores snapshots and checks content with hashes, so history is trustworthy.
  • It is free and open source.
  • Websites like GitHub made sharing and reviewing code easy for everyone.

2.5 Common mistakes

  • Confusing Git with GitHub. They are different things; Chapter 3 explains how.
  • Assuming Git is only for Linux. It runs on Windows, macOS and Linux.
Quick recap
  • Git was created in 2005 by Linus Torvalds after BitKeeper's free licence ended.
  • Its goals: speed, simple design, parallel work, distribution and integrity.
  • Junio Hamano has maintained Git since 2005.
  • GitHub arrived in 2008 and made Git popular far beyond the Linux community.

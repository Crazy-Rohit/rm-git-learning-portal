Git vs GitHub vs GitLab vs Bitbucket

Git is the tool that tracks your changes on your computer. GitHub, GitLab and Bitbucket are websites that host Git repositories online so teams can share and review them.

3.1 Analogy: the engine and the garage

Git is a car engine: it does the real work and runs on your own machine. GitHub is a big garage and showroom. It stores your car (the repository), lets other people see it, lets mechanics suggest improvements, and offers extra services such as testing. You can run the engine without the garage, but the garage is useless without the engine. Likewise, email is a technology and Gmail is a service built on it.

3.3 The main hosting platforms

All three use Git underneath, so the commands you learn work on each of them. This handbook uses GitHub for online examples because it is the most widely used and has a generous free plan.

PlatformKnown forTypical users
GitHubLargest community, open source, GitHub Actions, PagesIndividuals, open-source projects, companies of all sizes
GitLabBuilt-in CI/CD and DevOps tools; can be self-hostedTeams that want one integrated DevOps platform
BitbucketTight integration with Jira and other Atlassian toolsTeams already using Atlassian products

3.4 Common mistakes

  • Saying "I pushed to Git". You push to a remote such as GitHub. Git is the tool, GitHub is the place.
  • Treating GitHub as a guaranteed backup. It is hosting. Keep important repositories cloned in more than one place.
Caution

Check the visibility setting every time you create a repository. A private project made public by accident is hard to take back.

Quick recap
  • Git is a local version control tool; GitHub is an online service built around it.
  • GitLab and Bitbucket are alternatives and also use Git.
  • Git commands are the same on every platform.
Practice exercise
  • Create a free account at github.com with a professional username. It appears in your profile address and every contribution.
  • Add a profile photo and a one-line bio.

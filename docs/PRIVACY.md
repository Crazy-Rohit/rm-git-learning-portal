# Privacy

The progress record is public, because it lives on the `ledger` branch of this repository.

A learner file stores the GitHub username, the numeric GitHub id, stage dates, and the repository and commit ids used as evidence. It does not store an email address or a password.

The certificate, when stage 7 opens, will also store the name the learner types.

To ask for a record to be removed, open an issue on this repository. Removal deletes the learner file and, if a certificate exists, adds its id to `site/public/revoked.json`. Older copies can remain in Git history. That limit is part of using a public branch as the record.
